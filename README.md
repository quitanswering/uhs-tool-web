# UHS cluster tool — web UI

Онлайн-версия конфигуратора приборки (ретрофит GMC Acadia UHS в Opel Zafira C),
доступная по URL через GitHub Pages.

**Что работает прямо по URL (без машины):**
- Вся карта битов по блокам (02, 03, A1–A6) с русскими описаниями и именами параметров.
- Фильтры (включённые / известные / неизвестные), поиск.
- Бейдж исходного состояния в стоковой UHS (● вкл / ○ выкл) для каждого бита.
- Просмотр сохранённых конфигураций — папка `backups/`.

**Чтение/запись реальной приборки:**
Запусти локальный сервер с адаптером J2534 (`uhs_server.py` из приватного
репозитория с полным исходником). Эта страница сама свяжется с ним по
`http://127.0.0.1:8777` (браузер разрешает запросы с `*.github.io` на localhost),
и кнопки «Считать»/«Записать» заработают. Без адаптера — режим изучения.

Полный исходник (ядро J2534, запись, работа с ключом security) — в отдельном
приватном репозитории.
